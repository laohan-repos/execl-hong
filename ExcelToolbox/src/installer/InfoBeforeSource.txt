Excel 小工具箱 v1.0.0 — 安装前须知
========================================

本安装包为 Microsoft Excel 安装「Excel 小工具箱」功能区，提供删除空行、
一键去重、美化表头。需要 Windows 10/11 和桌面版 Microsoft Excel 2010 或以上。
仅有 WPS、Excel 网页版或 Office 运行时的电脑无法安装。

请先保存工作并关闭所有 Excel 窗口。

安装程序会在本机 Excel 中生成加载项，并用测试工作簿验证功能，
成功后才复制文件和注册加载项。无需 Python 或 Inno Setup，无需联网。
生成和测试可能需要几分钟，请等待完成。

生成期间会临时启用当前用户的「信任对 VBA 工程对象模型的访问」，
随后还原原来的设置。若公司策略禁止访问 VBA 工程，安装将失败，
请联系管理员。详细日志位于 %LOCALAPPDATA%\ExcelToolbox\Logs。

安装目录：%APPDATA%\Microsoft\AddIns\ExcelToolbox
仅对当前 Windows 用户安装，无需管理员权限。
该目录会登记为 Excel 的受信任位置，不修改全局宏禁用或受保护视图设置。
若企业策略禁止受信任位置，加载项仍可能被阻止。

删除空行、去重和美化操作都会先确认并在当前工作簿中建立备份工作表。
去重会删除整行，请确认选区已覆盖要保留的列。恢复数据请从备份表复制，
不要依赖 Ctrl+Z。工具仅处理当前活动的普通工作簿。

安装后重新打开 Microsoft Excel，顶部将出现「Excel 小工具箱」选项卡。
可在 Windows 设置的已安装应用中卸载。
