Excel 小工具箱 v1.0.0
===================

适用：Windows 10/11，桌面版 Microsoft Excel 2010 或以上。
不支持 WPS、网页版 Excel。安装到当前用户，无需管理员权限。

安装后重新打开 Microsoft Excel，在顶部「Excel 小工具箱」选项卡中使用：

1. 删除空行
   处理当前工作表 UsedRange 中既无值也无公式的整行。
   确认后备份原工作表，再删除空行。

2. 一键去重
   先选中连续矩形区域，选择第一行是否为表头。
   按所有选中列组合判重，不区分大小写，每组保留第一条记录。
   注意：删除的是工作表整行，请让选区覆盖需要保留的全部列。

3. 美化表头
   先选中区域，确认后备份原工作表。
   第一行设为蓝底白字、加粗、居中，并自动调整选中列宽。

备份与恢复
   每次实际操作前自动复制整张工作表，备份标签为橙色，名称以「备份_」开头。
   如需恢复，从备份工作表复制数据回原工作表；不要依赖 Ctrl+Z。
   请自行保存工作簿以保留结果及备份。

菜单未出现
   关闭所有 Excel，运行开始菜单中的「重新注册加载项（菜单未出现时）」。
   或 Excel → 文件 → 选项 → 加载项 → 管理「Excel 加载项」→ 转到 → 浏览，
   选择 %APPDATA%\Microsoft\AddIns\ExcelToolbox\ExcelToolbox.xlam 并勾选。
   若企业策略禁用宏或受信任位置，请联系管理员。

安全设置
   安装目录登记为 Excel 受信任位置，安装程序不修改全局宏禁用/受保护视图设置。
   安装时生成加载项的版本会临时开启 VBA 工程访问并还原，运行测试只使用临时工作簿。
   生成或测试失败时日志位于 %LOCALAPPDATA%\ExcelToolbox\Logs。

卸载
   先关闭 Excel，在 Windows 设置 → 应用中卸载「Excel 小工具箱」。
   卸载移除工具文件、加载项注册和工具目录的受信任位置。
   用户工作簿及其中的备份工作表不受影响。
